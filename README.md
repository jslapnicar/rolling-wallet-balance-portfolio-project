# rolling-wallet-balance-portfolio-project
OPIS: 
Podatkovni model in interaktivna nadzorna plošča za analizo simuliranega niza 1.000 bančnih transakcij. 
Model mora identificirati uporabnike, ki presegajo predlagane limite denarnic (npr. 1.000 €), in vizualizirati dnevne likvidnostne trende. 
<br>IZVEDBA: 
SQL: Uvoz in čiščenje transakcijskih podatkov.  Seštevek posameznih denarnic in identifikacija kršitve limitov (1.000 €). 
Power BI: Interaktivna nadzorna plošča z gumbom (button slicer) za dinamično preklapljanje med tipi transakcij ter graf za identifikacijo 10 uporabnikov z najvišjimi skupnimi vrednostmi transakcij.
